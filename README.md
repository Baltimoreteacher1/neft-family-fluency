# Neft Family Fluency

A free, week-by-week math fluency portal that families use at home. No accounts, no
names, no app store — open the link, pick an avatar, practice 5 minutes a day.

**MVP strand:** multiplication & division facts -> multi-digit division (8 weeks).
Long-term goal: a Grade 1-8 skill ladder.

Built by [Mr. Neft](https://neft-teacher-app-library.pages.dev), Grade 6 math,
Baltimore City Public Schools.

## Status

Phase 0 — scaffold. See `SETUP.md` for the steps that need a human, and `CLAUDE.md`
for the constraints every change has to respect.

## Development

```bash
npm install
npm test          # unit tests
npm run test:e2e  # Playwright e2e
npm run serve     # http://localhost:8080
```
